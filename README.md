## VIZION STORE 61 — E-commerce de Moda Masculina

E-commerce desenvolvido para a **VIZION STORE 61**, com foco em uma experiência de compra moderna, responsiva e intuitiva.

O projeto foi desenvolvido utilizando **Next.js, React e TypeScript**, com integração a **API REST em PostgreSQL** para gerenciamento e persistência dos dados.

A aplicação conta com catálogo de produtos, categorias, informações de estoque, carrinho de compras e estrutura preparada para gerenciamento de pedidos e clientes.

### Tecnologias utilizadas

* **Next.js**
* **React**
* **TypeScript**
* **PostgreSQL**
* **API REST**
* **Tailwind CSS**
* **Git/GitHub**
* **Vercel**

O projeto foi desenvolvido com foco em **performance, responsividade, organização de código e experiência do usuário**, utilizando uma arquitetura moderna para aplicações web.
